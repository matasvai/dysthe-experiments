03 Numerical qualification

AWAITING DATA

Each input needs its own resolution and boundary checks. Qualifying a solitary profile does not qualify every packet.

How to read these diagnostics +
Peak amplitude
Maximum envelope modulus |u| on the numerical grid at the selected ξ.
RMS width
Action-weighted root-mean-square extent around the packet center; it can increase when a small tail travels far from the core.
Displacement
Packet-center shift relative to ξ = 0. Translation and phase drift must be separated from genuine deformation.
Exterior action
Fraction of ∫|u|² dτ outside a moving core window. This includes pre-existing tails and dispersive transport; it is a radiation proxy, not a radiation measurement.
Accuracy limits
Conservation traces alone do not establish accuracy. Grid, step and domain comparisons apply to the case and propagation interval actually checked. Short persistence is not a stability result.
